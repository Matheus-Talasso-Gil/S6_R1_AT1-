# Dicionário de HTML: Imagens

Conceitos importantes para inserir imagens em páginas e torná-las mais acessíveis.

## Estrutura do HTML

| Termo | Significado |
| --- | --- |
| **HTML** | Linguagem usada para estruturar o conteúdo de uma página web. |
| **Tag** | Elemento que organiza o conteúdo, escrito entre sinais de menor e maior, como `<img>`. |
| **Atributo** | Informação adicionada a uma tag para configurar ou descrever o elemento. |

## Imagens

| Termo | Significado |
| --- | --- |
| **`img`** | Tag usada para inserir uma imagem na página. |
| **`src`** | Atributo que indica o endereço ou caminho do arquivo de imagem. |
| **Caminho relativo** | Endereço de um arquivo indicado a partir da localização da página, como `imagens/logo.png`. |

## Acessibilidade

| Termo | Significado |
| --- | --- |
| **`alt`** | Texto alternativo que descreve a imagem para leitores de tela ou quando ela não carrega. |
| **Acessibilidade** | Prática de tornar páginas e conteúdos utilizáveis por pessoas com diferentes necessidades. |

## Exemplo

```html
<img src="imagens/senai.svg" alt="Logotipo do SENAI">
```

Nesse exemplo, `src` indica o caminho do arquivo, e `alt` descreve a imagem.
